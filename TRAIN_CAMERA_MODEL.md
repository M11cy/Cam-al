# Быстрое дообучение модели под эту камеру

Схема классов для первого эксперимента:

```text
person
phone
other_object
```

`other_object` - это предметы, которые похожи на телефон, но не должны запускать тревогу: вейп, расчёска, банка, упаковка, ключи, маленькая коробка.

## 1. Собрать кадры

Автоматически собрать 100 кадров с камеры:

```bash
.venv/bin/python tools/capture_frames.py --camera 0 --count 100 --interval 1
```

Если камера другая:

```bash
.venv/bin/python tools/capture_frames.py --camera 1 --count 100 --interval 1
```

Можно собирать вручную: нажимать `Space`, чтобы сохранить кадр.

```bash
.venv/bin/python tools/capture_frames.py
```

## 2. Разметить кадры

Можно начать с авторазметки. Скрипт создаст черновые labels в `dataset/labels_draft`, а исходные кадры не изменит:

```bash
.venv/bin/python tools/auto_label_dataset.py --model yolov8s.pt --imgsz 960
```

Если уже есть первая обученная модель, лучше авторазмечать ей:

```bash
.venv/bin/python tools/auto_label_dataset.py --model runs/detect/shop-phone/weights/best.pt --imgsz 960
```

После этого откройте редактор. Он автоматически подгрузит черновые рамки из `dataset/labels_draft`, их останется поправить и подтвердить:

```bash
.venv/bin/python tools/annotate_dataset.py
```

Клавиши:

- `p` - выделить сотрудника;
- `t` - выделить телефон;
- `o` - выделить похожий предмет как `other_object`;
- `u` - отменить последнюю рамку;
- `c` - очистить все рамки на текущем кадре;
- `n` - сохранить кадр и перейти дальше;
- `s` - сохранить кадр без объектов;
- `q` - выйти.

Как рисовать рамку:

1. Нажмите `p`, `t` или `o`, чтобы выбрать класс.
2. Зажмите левую кнопку мыши на объекте.
3. Протяните рамку вокруг объекта.
4. Отпустите кнопку мыши - рамка добавится автоматически.
5. Когда все объекты на кадре размечены, нажмите `n`.

Для первого теста хватит 200-500 размеченных кадров. Для стабильной работы на одной камере лучше собрать 1000-3000 кадров с разным светом, позами, телефонами и похожими предметами.

Важно: на каждом кадре нужно разметить все видимые объекты ваших классов: `person`, `phone`, `other_object`. Если телефон размечен, а человек рядом не размечен, модель будет учиться считать этого человека фоном.

## 3. Дообучить модель

```bash
.venv/bin/python tools/train_custom_model.py --model yolov8s.pt --epochs 80 --imgsz 960 --batch 4 --device 0
```

Следующую итерацию можно дообучать уже от предыдущего результата:

```bash
.venv/bin/python tools/train_custom_model.py --model runs/detect/shop-phone/weights/best.pt --epochs 50 --imgsz 960 --batch 4 --device 0 --name shop-phone-v2
```

Готовая модель появится примерно здесь:

```text
runs/detect/shop-phone/weights/best.pt
```

Если запускать обучение несколько раз, папка может получить номер:

```text
runs/detect/shop-phone2/weights/best.pt
```

## 4. Подключить модель

Скопируйте лучший результат в папку `models`:

```bash
mkdir -p models
cp runs/detect/shop-phone/weights/best.pt models/shop-camera-phone.pt
```

После этого приложение автоматически будет использовать локальную модель, обученную под эту камеру.
