# Обучение модели под конкретную камеру

Этот README описывает, как обучить YOLO-модель под конкретную камеру и конкретное рабочее место. Цель обучения - чтобы модель лучше отличала телефон от похожих предметов именно в вашем ракурсе: вейпа, расчёски, банки, упаковки и других объектов.

## Общая идея

Стандартная модель YOLO уже умеет находить класс `cell phone`, но она обучена на общих изображениях. В магазине камера может стоять далеко, смотреть сверху или сбоку, а телефон может выглядеть похоже на другие небольшие предметы.

Поэтому модель нужно дообучить на кадрах именно с этой камеры:

- тот же ракурс;
- то же освещение;
- та же рабочая зона;
- реальные сотрудники;
- реальные предметы, которые модель путает с телефоном.

После обучения получится локальный файл модели, например:

```text
models/shop-camera-phone.pt
```

Его можно подключить в приложение вместо стандартной модели.

## Какие кадры собрать

Для первого теста достаточно 300-500 кадров. Для более уверенной работы лучше собрать 1000+ кадров.

Нужны разные ситуации:

- сотрудник с телефоном в руке;
- сотрудник смотрит вниз в телефон;
- сотрудник без телефона;
- сотрудник смотрит вниз без телефона;
- телефон лежит на столе;
- телефон рядом с рабочим местом, но не в руке;
- пустая рабочая зона;
- похожие предметы: вейп, расчёска, банка, упаковка, ключи, небольшие коробки;
- разные сотрудники;
- разное освещение: день, вечер, тени, яркий свет.

Важно добавлять не только хорошие примеры телефона, но и плохие примеры, где модель ошибается. Если модель приняла упаковку за телефон, такой кадр нужно добавить в датасет и разметить упаковку как отдельный класс.

## Какие классы размечать

Рекомендуемый набор классов:

```text
person
phone
vape
comb
can
package
```

Можно добавить свои классы, если на рабочем месте есть другие похожие предметы:

```text
keys
wallet
box
remote
```

Лучше явно размечать похожие предметы отдельными классами. Тогда модель учится не просто искать телефон, а отличать телефон от конкретных объектов, которые встречаются в кадре.

## Чем размечать

Подойдут инструменты:

- CVAT;
- Roboflow;
- Label Studio;
- LabelImg.

При экспорте выбирайте формат:

```text
YOLOv8 / Ultralytics YOLO
```

## Структура датасета

После разметки датасет должен выглядеть так:

```text
dataset/
  images/
    train/
    val/
  labels/
    train/
    val/
  data.yaml
```

Пример:

```text
dataset/images/train/frame_001.jpg
dataset/labels/train/frame_001.txt
dataset/images/val/frame_120.jpg
dataset/labels/val/frame_120.txt
```

У каждой картинки должен быть `.txt` файл с разметкой YOLO. Если на кадре нет объектов, `.txt` может быть пустым.

## Пример `data.yaml`

```yaml
path: dataset
train: images/train
val: images/val

names:
  0: person
  1: phone
  2: vape
  3: comb
  4: can
  5: package
```

Порядок классов в `data.yaml` должен совпадать с порядком классов в разметке.

## Обучение на macOS или Linux

```bash
source .venv/bin/activate
yolo detect train model=yolov8n.pt data=dataset/data.yaml epochs=80 imgsz=640 batch=8
```

Если компьютер слабый, можно уменьшить параметры:

```bash
yolo detect train model=yolov8n.pt data=dataset/data.yaml epochs=50 imgsz=480 batch=4
```

## Обучение на Windows

```bat
.venv\Scripts\activate
yolo detect train model=yolov8n.pt data=dataset\data.yaml epochs=80 imgsz=640 batch=8
```

Если компьютер слабый:

```bat
yolo detect train model=yolov8n.pt data=dataset\data.yaml epochs=50 imgsz=480 batch=4
```

## Где будет готовая модель

После обучения лучшая модель появится здесь:

```text
runs/detect/train/weights/best.pt
```

Если запускать обучение несколько раз, папка может называться:

```text
runs/detect/train2/weights/best.pt
runs/detect/train3/weights/best.pt
```

Скопируйте лучшую модель в папку `models`:

```text
models/shop-camera-phone.pt
```

## Как подключить модель к приложению

В `app.py` замените:

```python
MODEL_NAME = "yolov8n.pt"
```

на:

```python
MODEL_NAME = "models/shop-camera-phone.pt"
```

Pose-модель можно оставить стандартной:

```python
POSE_MODEL_NAME = "yolov8n-pose.pt"
```

После этого приложение будет использовать вашу локальную обученную модель.

## Как проверять качество

После обучения нужно протестировать модель на новых кадрах, которые не участвовали в обучении.

Проверяйте:

- находит ли телефон в руке;
- пропускает ли телефон, если камера далеко;
- путает ли телефон с вейпом, расчёской, банкой или упаковкой;
- находит ли телефон на фоне, где он не важен;
- работает ли модель при другом освещении;
- видит ли модель телефон у разных сотрудников.

Если модель ошибается, добавьте эти кадры в датасет, разметьте их и обучите ещё раз. Это нормальный цикл:

```text
собрать кадры -> разметить -> обучить -> проверить -> добавить ошибки -> дообучить
```

## Важное ограничение

Даже обученная модель может иногда определять похожие предметы как телефон. Но в рабочей логике приложения это дополнительно фильтруется:

- телефон должен быть рядом с рукой;
- голова сотрудника должна быть наклонена вниз;
- объект должен оставаться видимым достаточно долго;
- тревога включается не от одного случайного кадра, а по таймеру.

Именно сочетание обученной модели и поведенческих признаков даёт более стабильный результат.
